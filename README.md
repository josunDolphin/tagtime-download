# 태그타임 다운로드

휴대폰이 NFC 리더기 신호를 받은 시각을 기록하고 메모를 남기는 Android 앱입니다.

## 다운로드

**[최신 APK 다운로드](https://github.com/josunDolphin/tagtime-download/releases/latest/download/tagtime.apk)**

[버전별 변경 내용](https://github.com/josunDolphin/tagtime-download/releases)

## 설치

1. Android 휴대폰에서 위 APK를 다운로드하고 엽니다.
2. 설치가 제한되면 Android 안내에 따라 다운로드에 사용한 브라우저 또는 파일 앱의 ‘이 출처 허용’을 켭니다.
3. 설치 후 태그타임을 열고 NFC를 켭니다. 출입 리더기 기록을 사용할 때는 ‘자동 기록’을 켜고 알림 권한을 허용합니다.
4. 업데이트는 새 APK를 내려받아 기존 앱 위에 설치하세요.

일반 NFC 태그 읽기는 Android 8.0 이상, 출입 리더기 신호 감지는 Android 16 이상이 필요합니다. 실제 수신은 휴대폰과 리더기의 지원 여부에 따라 달라집니다. 태그 시각은 문 열림이나 출입 성공을 확인한 시각이 아닙니다.

## 임시 배포 안내

지인 테스트용 APK입니다. 운영자가 임시 배포를 종료하면 앱이 온라인에서 종료 정책을 받은 후 사용이 중단될 수 있습니다. 기록은 기기에 저장되므로 보관할 내용은 앱 메뉴에서 CSV로 내보내세요.
